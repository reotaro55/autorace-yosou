# オートレース予想 検証ツール

AUTORACE.JP（公式）から出走表と結果を取得し、事前に確定した買い目で的中率・回収率を検証する。

## 準備
```
pip install requests
```

## 使い方
```
# 出走表（ハンデ・車級・試走T・偏差・連率・直近3走・リプレイURL）
python cli.py program kawaguchi 2026-11-03 8

# 買い目を確定記録（本命3点＋対抗3点。記録時刻つきで追記のみ）
python cli.py pick kawaguchi 2026-11-03 8 --honmei "3-6-7,3-7-6,6-3-7" --taikou "6-7-3,7-3-6,3-6-4"

# 変更するときは理由が必須（追加する根拠と削る根拠）。変更前の行も残る
python cli.py pick kawaguchi 2026-11-03 8 --honmei "..." --taikou "..." --reason "..."

# 見送り / ルールだけで出した予想は --kind 数値 で分けて記録
python cli.py pick kawaguchi 2026-11-03 9 --skip

# 結果と3連単払戻、周回ごとの隊列を取得
python cli.py results kawaguchi 2026-11-03 1-12

# 検証集計（裁量予想と数値予想を分けて表示）
python cli.py report
```
場コード: kawaguchi / isesaki / hamamatsu / iizuka / sanyou

## 数値ルールの自動予想
- `rules/` にルールを版ごとに置く。v1は試走T＋偏差＋ハンデ、v2はそれに近10走の平均ST（3倍）を加える。記事とDiscordは最新版、古い版は比較用に買い目だけ記録。試走T＋偏差で競走タイムを見積もり、ハンデ分を含めた走破時間が短い順に並べて本命3点・対抗3点を作る
- GitHub Actions（watch.yml）が日本時間8:41に起動し、深夜1時まで90秒おきに開催場を確認して、試走タイムが揃ったレースを締切前に台帳へ記録（種別「数値」、ルール版つき）
- 締切後や結果取得後の記録は集計しない
- ルールの改良は v2, v3 … を新しく置く形で行い、過去の記録は書き換えない。成績はルール版ごとに分けて集計

## 守っているルール
- 結果を取得したレースには買い目を記録できない。結果取得後に書かれた行は「集計外」
- 払戻が取れないレースは「払戻未確認」として集計しない（推測しない）
- 見送り・欠車は別扱い。欠車があったレースは要確認の注記を出す
- 検証は記録した1点金額で計算。実際の購入額（--actual）は別の欄に残す

## データ
- `data/program/`, `data/result/` に公式の生データ（JSON）を保存
- `data/picks.csv` が買い目台帳
- 結果には周回ごとの隊列（grandNoteList）が入るので、「何周目で追いついたか・抜けたか」の記録に使える

## 既存の実績（2026-11-02 川口5〜8R）
買い目の明細が手元にないため台帳には入れていない。集計のみ:
4レース中1的中（5R 6-4-3 払戻1,370円）、投資2,400円、回収率57.1%、収支−1,030円。

## 注意
- 公式ページが内部で使っているAPIを、ページを開いたときと同じ形で呼んでいる。仕様が変わると取得できなくなる
- アクセス間隔は1.5秒空けている
